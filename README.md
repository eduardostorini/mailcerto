# MailCerto

Ferramenta open source para diagnóstico de domínios, DNS, servidores de e-mail, autenticação, reputação, SMTP, TLS e segurança.

## Requisitos de Desenvolvimento

- Python 3.11 ou superior
- Instale as dependências:
  ```bash
  pip install -r requirements.txt
  ```

## Como Executar

```bash
python mailcerto/app.py
```

## Como Executar Testes

```bash
pytest
```
