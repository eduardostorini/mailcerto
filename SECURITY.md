# Política de Segurança

## Reportando Vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança no MailCerto, **não abra uma issue pública**. Em vez disso, envie um e-mail para segurança em seu-email@exemplo.com com os detalhes.

Por favor, inclua:

1. Descrição da vulnerabilidade
2. Passos para reproduzir (se possível)
3. Impacto potencial
4. Versões afetadas

## Compromissos

- Reconheceremos o relatório em 48 horas
- Nos esforçaremos para corrigir e liberar uma atualização em 7-14 dias
- Você será creditado na nota de lançamento (a menos que prefira ser anônimo)

## Versions Suportadas

| Versão | Suportada         |
|--------|-------------------|
| 1.0.x  | ✅ Sim             |
| < 1.0  | ❌ Não             |

## Práticas de Segurança

O MailCerto segue as seguintes práticas de segurança:

- Todas as dependências são regularmente atualizadas
- Testes de segurança são executados em cada CI/CD
- Criptografia é usada para operações sensíveis
- Nenhum dado confidencial é logado
